# Prompt Log

Folder ini menyimpan catatan prompt AI yang dipakai selama pengembangan, beserta hasil dan tindak lanjutnya. Tujuannya transparansi dan reproducibility, bukan arsip percakapan mentah.

## Aturan

- Satu entri per tujuan, nama `NNNN-kebab-title.md`.
- Jangan menyimpan secret, token, kredensial, data pribadi, atau isi `.env`.
- Ringkas prompt panjang; fokus pada tujuan, batasan, dan hasil.
- Catat apa yang diubah manusia setelah keluaran AI.
- Tautkan dokumen atau commit yang dihasilkan.

## Kapan menambah entri

- Prompt yang menghasilkan keputusan arsitektur.
- Prompt yang menghasilkan kode atau konfigurasi non-trivial.
- Prompt yang menghasilkan dokumentasi penting.
- Prompt yang gagal dan perlu diperbaiki (berguna sebagai pelajaran).
